# 相册屏幕管家 / PhotoScreenGuard

轻量、原生 Java Android 应用，最低支持 Android 8.0（API 26）。无需 Root，无网络权限，不采集信息。

## 工作模式

- 工作日、周末分别设定活跃时间段：例如 `07:00-08:30,12:00-13:30,18:00-23:00`。
- 活跃时间段内按自定义时长在正常亮度和低亮度之间循环。
- 非活跃时段保持低亮度，避免常亮相册长期高亮。
- 支持修改两种亮度、两种时长、工作日/周末时间段，保存到本地。
- 通过 Android 前台服务执行亮度调度，每 15 秒检查一次。
- 重启后尝试自动启动；在华为系统中还需设置允许自启动与后台运行。
- 停止时恢复原来的亮度和自动亮度模式。

**注意**：暂不包含自动息屏、自动亮屏、充电控制、法定节假日调休识别。即使 Root 也不是当前功能的必要条件。

## 生成 APK

方式 A：Android Studio（推荐）。安装 Android Studio 和 Android SDK 35，打开项目目录，等待 Gradle 同步，选择 `Build > Build APK(s)`。得到 `app/build/outputs/apk/debug/app-debug.apk`，这是直接安装的 APK，不是 APKM。

方式 B：GitHub Actions。将整个目录上传到 GitHub 仓库，进入 Actions -> Build Android APK -> Run workflow，构建完成后下载 `PhotoScreenGuard-Android8-APK` Artifact，并解压取得 `app-debug.apk`。Workflow 为自动化编译配置，尚未在 CI 实测。

## 在华为 Android 8 中安装

将 APK 复制到平板，允许“安装未知应用”，安装并打开。点击“授予修改系统亮度权限”，授权后输入设置并点“保存并启动”。如果服务被华为省电系统关闭，进入系统设置的应用启动管理，允许自动启动、关联启动和后台活动。部分 EMUI 版本可能还需关闭对该应用的电池优化。

## 注意

1. 非活跃时间保持低亮度，不会自动息屏，也不自动唤醒设备。
2. Android 系统亮度的百分比是近似换算到 1～255，并不代表实际亮度（尼特）的线性百分比。
3. 由于 Android 8/华为系统对后台服务的策略差异，需真机安装验证开机自启和长时间稳定性。
4. 亮度循环仅减少高亮运行时间，不能保证延长具体使用寿命。
